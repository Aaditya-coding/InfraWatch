# Contributing

1. Pull the latest `main`.
2. Create a focused branch: `feat/...`, `fix/...`, or `docs/...`.
3. Commit small, meaningful changes.
4. Run tests and basic checks.
5. Open a pull request into `main`.
6. Ask the other teammate for review before merging.

Suggested branches:
- `feat/sensor-simulator`
- `feat/anomaly-detection`
- `feat/streamlit-dashboard`
- `feat/risk-explanations`
